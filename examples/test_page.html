What's Happening

This test demonstrates how Ollama can use the Model Context Protocol (MCP) to interact with your browser.

The process works as follows:

  1. The test script sends a prompt to Ollama
  2. Ollama processes the MCP command in the prompt
  3. The MCP module forwards the command to the browser MCP server
  4. The browser MCP server opens this page in your default browser
